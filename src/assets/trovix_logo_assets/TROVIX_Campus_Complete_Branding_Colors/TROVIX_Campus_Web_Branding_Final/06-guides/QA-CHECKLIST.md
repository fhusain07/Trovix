# Acceptance checklist for SMS Web

- [ ] Full logo legible on light mode screens
- [ ] Full logo legible on dark mode screens
- [ ] Short T icon visible in collapsed sidebar
- [ ] Favicon shown in Chrome light & dark tab UI after hard refresh
- [ ] PWA icon (if app has a PWA manifest) not clipped
- [ ] Manual light/dark preference takes precedence over OS setting
- [ ] Sidebar custom colors remain unchanged when branding is applied
- [ ] Custom sidebar color persists after refresh, logout/login, and tenant switch as before
- [ ] Existing school-specific logos remain when white-label rules demand it
- [ ] No layout overflow in responsive/mobile sidebar
- [ ] No regression in routes, forms, auth, API requests, or UI functionality
- [ ] Build, lint, tests and screenshot comparison reviewed
- [ ] No unexpected production config or persistent data changes
